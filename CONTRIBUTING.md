# Contributing

Thanks for contributing to this project! 🎉

## How to contribute

1. Fork the repository.

2. Create a branch for your changes:

   ```bash
   git checkout -b feature/my-change
   ```

3. Make your changes and test them.

4. Commit and push your branch.

5. Open a Pull Request describing what you changed.



## Guidelines

- Keep Python examples simple and beginner-friendly.
- Follow the existing project structure and style.
- Make sure code examples work correctly.
- Keep changes focused and avoid unrelated modifications.
- Be respectful and constructive in discussions and reviews.



Thank you for helping improve the project! ❤️
