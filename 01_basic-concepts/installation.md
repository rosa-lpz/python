# Python installation

## Linux

### Python
````bash
sudo apt install python3
````
### Python Package Manager (pip)
````bash
sudo apt install python3-pip
````

### Pip
 Install pip via the system package manager
````bash
sudo apt install python3-pip
````
Check version
````bash
python3 -m pip --version
````
