# Python Built-in Libraries
Python comes with a large standard library (built-in libraries) that you can use without installing anything. Here are some of the most commonly used ones:
| Library           | Purpose                                                                    |
| ----------------- | -------------------------------------------------------------------------- |
| `math`            | Mathematical functions (`sqrt`, `sin`, `pi`)                               |
| `random`          | Generate random numbers and make random selections                         |
| `os`              | Interact with the operating system (files, folders, environment variables) |
| `sys`             | Access Python runtime information and command-line arguments               |
| `datetime`        | Work with dates and times                                                  |
| `time`            | Time-related functions (sleep, timestamps)                                 |
| `json`            | Read and write JSON data                                                   |
| `csv`             | Read and write CSV files                                                   |
| `re`              | Regular expressions (pattern matching)                                     |
| `collections`     | Specialized containers like `Counter`, `deque`, `defaultdict`              |
| `itertools`       | Efficient looping and iterator tools                                       |
| `functools`       | Higher-order functions like `lru_cache` and `reduce`                       |
| `statistics`      | Mean, median, mode, variance, etc.                                         |
| `pathlib`         | Object-oriented file and path handling                                     |
| `shutil`          | Copy, move, and archive files                                              |
| `sqlite3`         | Built-in SQLite database support                                           |
| `hashlib`         | Hashing algorithms (SHA-256, MD5, etc.)                                    |
| `heapq`           | Heap (priority queue) algorithms                                           |
| `bisect`          | Binary search in sorted lists                                              |
| `threading`       | Multithreading                                                             |
| `multiprocessing` | Parallel processing                                                        |
| `asyncio`         | Asynchronous programming                                                   |
| `socket`          | Network communication                                                      |
| `urllib`          | Fetch data from URLs                                                       |
| `http`            | HTTP client and server utilities                                           |
| `logging`         | Logging messages and debugging                                             |
| `argparse`        | Parse command-line arguments                                               |
| `typing`          | Type hints                                                                 |
| `enum`            | Enumerations                                                               |
| `decimal`         | High-precision decimal arithmetic                                          |
| `fractions`       | Exact rational numbers                                                     |
| `string`          | String constants and helper functions                                      |
| `gzip`            | Read and write gzip-compressed files                                       |
| `zipfile`         | Create and extract ZIP archives                                            |
| `tarfile`         | Work with TAR archives                                                     |
